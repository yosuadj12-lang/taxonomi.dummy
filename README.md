# Taxonomi (dummy)

Repository uji coba untuk **Taxonomi**, website latihan ujian sertifikasi konsultan pajak berkonsep kebun bunga.

## Isi saat ini

- `index.html`: prototipe Garden Mode (satu file, bisa langsung dibuka di browser)
  - Kebun 8 mata ujian, ukuran tanaman sesuai bobot ujian
  - Menyiram = latihan 10 soal (minimal 6 benar), jadwal siram 2/3/5 hari
  - Mode ujian: layar penuh, deteksi pindah tab, timer 10 menit, jawaban tampil setelah dikumpulkan
  - Kalender riwayat per bulan
  - Halaman masuk/daftar (tampilan saja, belum terhubung ke server)

## Catatan

Ini masih prototipe. Login, password, dan data kebun belum tersimpan di server.
Versi sungguhan akan memakai Supabase (login dan database) dan dipasang di Vercel.
